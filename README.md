# 🏠 合租找房比較器

> 多人合租找房比較工具：表格對比、地圖瀏覽、雷達圖分析、投票決策。
> 串接 Google Sheets 即時同步，不需架站、不花錢。

## 🚀 快速開始

### 第二步：設定 Google Apps Script

1. 在 Google Sheet 上方選單 → **擴充功能** → **Apps Script**
2. 刪除預設程式碼
3. 將 `google-apps-script/Code.gs` 的完整內容貼入
4. 新增 Cheerio 程式庫：
   - 左側選單 → **程式庫**（Libraries）→ 點「+」
   - 輸入 Script ID：`1ReeQ6WO8kKNxoaA_O0XEQ589cIrRvEBA9qcWpNqdOP17i47u6N9M5Xh0`
   - 選擇最新版本 → **新增**
5. 部署為 Web App：
   - 右上角 **部署** → **新增部署作業**
   - 類型：**網頁應用程式**
   - 說明：合租找房比較器 API
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 點擊 **部署** → 複製產生的 URL

> ⚠️ 首次部署需要授權。點擊「授權」→「進階」→「前往（你的專案名稱）」

### 第三步：設定自動抓取觸發器（選用）

1. 在 Apps Script 編輯器左側 → **觸發條件**（Triggers）
2. 點右下角 **+ 新增觸發器**
3. 設定：
   - 函式：`onEditTrigger`
   - 事件來源：試算表
   - 事件類型：**編輯時**
4. 儲存

設定完成後，在 A 欄貼入網址就會自動抓取！

### 第四步：使用網頁

#### 方法 1：直接開啟（Demo 模式）
直接用瀏覽器開啟 `index.html`，會以內建的示範資料運作。

#### 方法 2：連接 Google Sheets
開啟網頁後，點擊右上角的「投票者名稱」按鈕，在設定中：
- 貼入 Apps Script Web App URL
- 輸入你的暱稱
- 設定合租人數

#### 方法 3：透過 URL 參數
```
https://你的帳號.github.io/rent-compare/?api=SCRIPT_URL&voter=小明
```

每位室友用不同的 `voter` 參數：

## 📋 使用流程

```
1. 新增物件（三種方式擇一）：
   a. 網頁右上角「➕ 新增物件」→ 把租屋頁面全選複製貼上 → 自動解析 → 送出
   b. 在租屋頁面點書籤小工具「➕ 傳送至比較器」
   c. 直接在 Google Sheet A 欄貼網址（自動抓取，591 可能被擋）
2. 在 K 欄填寫優缺點標籤（逗號分隔）：採光好, 近捷運, 無陽台
3. 開啟網頁 → 自動載入所有資料
4. 用表格的「狀態」下拉選單追蹤進度：候選 → 已約看 → 已看 → 淘汰/簽約
5. 切換表格 / 地圖 / 比較檢視，點擊標籤篩選
6. 在表格中**點任一列展開**，即可打星星投票（1-5 分）＋ 留言，所有人的留言會顯示成討論串
7. 在比較檢視調整「你在乎什麼」權重，看加權總分排行榜
8. 達成共識，恭喜找到新家！🎉
```

## ❓ FAQ

**Q：591 抓不到資料怎麼辦？**
A：由於 591 設有嚴格的防爬蟲機制，Apps Script 伺服器去爬網頁容易被阻擋。

#### ✨ 解法 ：網頁內建「➕ 新增物件」（零安裝，最簡單）
1. 在 591 物件頁面按 `Ctrl/Cmd + A` 全選 → `Ctrl/Cmd + C` 複製
2. 回到比較器網頁，點右上角 **「➕ 新增物件」**
3. 把內容貼進大框框，系統自動解析出名稱、租金、坪數、格局、樓層、地址、押金
4. 檢查／補齊欄位後點「送出至試算表」，完成！（地址會自動轉成地圖座標）

**Q：室友可以留言討論嗎？**
A：可以！在「投票」頁面，每個物件下方都有留言框，投票時一併送出。所有人的留言會顯示成討論串，表格檢視的投票欄也會顯示「💬 N 則意見」（滑鼠移上去可預覽）。

**Q：「加權總分排行」是什麼？**
A：在「比較檢視」中，每個人可以依自己重視的程度，調整租金／坪數／交通／設施／投票／通勤的權重（0-5），系統會即時算出所有物件的加權總分排行。權重只存在各自的瀏覽器，所以每位室友可以有不同的偏好，互相看看彼此的第一名是誰，更容易聊出共識。

**Q：更新了 Code.gs 之後要做什麼？**
A：貼入新版 Code.gs 後，記得到右上角 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。如果是「新增部署作業」則會產生新網址，要記得更新到網頁設定中。

**Q：標籤可以自訂嗎？**
A：可以！在「標籤定義」工作表新增一列，填入標籤名稱、分類、顏色和 Emoji。網頁重新整理後就會生效。

**Q：投票可以改嗎？**
A：可以，再投一次相同物件就會自動更新分數。

**Q：手機可以用嗎？**
A：可以，網頁有響應式設計，手機瀏覽體驗良好。
