## 升級步驟（約 5 分鐘）

### 1. 替換前端檔案
把這個資料夾的 `index.html`、`css/index.css`、整個 `js/` 資料夾覆蓋到你的 GitHub repo，push 上去即可。
（`js/commute.js` 和 `js/quick-add.js` 是新檔案）

### 2. 更新 Google Apps Script ⚠️ 必做
1. 開啟試算表 → 擴充功能 → Apps Script
2. 用新版 `google-apps-script/Code.gs` 完整取代舊程式碼
3. **部署 → 管理部署作業 → 編輯（鉛筆圖示）→ 版本選「新版本」→ 部署**
   > 用「編輯」更新現有部署，網址不會變；如果用「新增部署作業」會產生新網址，記得更新到網頁設定。

### 3. 更新 Google Sheet
1. 「物件資料」工作表的 **Q1 儲存格**填入標題：`看房狀態`（既有物件留空即視為「候選」）
2. （選用、推薦）新增工作表 **`通勤目的地`**，欄位：

   | A | B | C | D |
   |---|---|---|---|
   | 名稱 | 地址 | 緯度 | 經度 |
   | 小明公司 | 台北市中正區北平西路3號 | | |

   緯度經度留空，系統會自動補上。

### 4. 完成！
重新整理網頁，應該會看到：右上角的「➕ 新增物件」、表格的「狀態」和「通勤」欄、投票頁的留言框、比較檢視的權重滑桿和排行榜。

## 注意事項
- 權重設定存在各自的瀏覽器（localStorage），每位室友可以不同
- 通勤距離是「直線距離」，實際路程約再乘 1.3，僅供物件之間相對比較
- 留言會寫入「投票」工作表的 D 欄（原本就有此欄位，無需改表）
